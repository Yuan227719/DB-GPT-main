# ECC 箱线图口径（FBC / ads_fa_fbc_cycle）

> 来源：DolphinScheduler `sub_st_embed_ods_to_ads` → `to_ads_fbc_ecc_cycle_box`（cycle 级）、`to_ads_fbc_ecc_wo_box`（WO 级）、`周报_WEEK_通用` → `to_slc_wo/to_tlc_wo/to_qlc_wo`（周ECC箱线），及现算箱线模板（多工单/多cycle/多批次，grain='sn_cycle'）（2026-08-11）。

## 业务定义
ECC 值的分布箱线图。三类：
1. **落表箱线**（`ads_fa_fbc_cycle`，ETL 预计算，grain='wo_cycle'），两种 box_type：
   - **`ECC_CYCLE`**（cycle 箱线）：按 `wo × cycle_number × ecc_type(ECC_SLC/TLC/QLC) × wo_status × flash` 粒度
   - **`ECC_WO`**（WO 箱线）：按 `wo × ecc_type × wo_status × flash` 粒度，一个工单汇总所有 cycle
2. **周ECC箱线**（`dws_indicator_w`，`{flash_pn}_ecc_slc_wo` / `_ecc_tlc_wo` / `_ecc_qlc_wo`，见下方第三大部分）
3. **现算箱线**（grain='sn_cycle'，按需现算，见下方第二大部分）：多工单 / 多cycle / 多批次 三种粒度

每个桶输出：`q1 / median(q2) / q3 / iqr / upper / lower / outliers / count_total`，用于画箱线图（须线、离群点）。

## 算法步骤（各粒度一致，仅分组维度/数据源不同）
1. **源**：`dws_fa_ecc_cycle_stat`（每行 = 某桶内某个 ecc_value 的计数 `ecc_cnt`）；落表箱线 `grain='wo_cycle'`，周ECC/现算箱线 `grain='sn_cycle'`
2. **累积计数**：按分组窗口 `SUM(ecc_cnt) OVER (PARTITION BY <分组> ORDER BY ecc_value)` 得 `slice_count_total`；`count_total` = 窗口内总计数
3. **四分位位置（理论序号）**：`q1_pos = count_total * 0.25`，`q2_pos = 0.5`，`q3_pos = 0.75`
4. **取四分位 ecc_value**：`q1/q2/q3` = 第一个 `slice_count_total >= q位置` 的 `ecc_value`
   （即样本量加权后达到 25%/50%/75% 位置的 ECC 值）
5. **须线（clamp 到真实数据范围）**：
   - `upper = LEAST(q3 + 1.5*(q3-q1), max_ecc)`
   - `lower = GREATEST(q1 - 1.5*(q3-q1), min_ecc)`
   - `max_ecc/min_ecc` = 该桶内 ecc_value 的实际最大/最小
6. **离群值**：`outliers = collect_set/ecc_value` 中满足 `v > upper or v < lower` 的值（JSON 数组）
7. 落表箱线输出到 `ads_fa_fbc_cycle`，`box_type` 区分 CYCLE/WO；周ECC/现算箱线写入/返回 `q1/median/q3/iqr/upper/lower/outliers/count_total`

## 直接查表（落表箱线）
```sql
SELECT wo, cycle_number, ecc_type, wo_status, box_type, flash_pn,
       q1, median, q3, upper, lower, outliers, count_total
FROM st_embed.ads_fa_fbc_cycle
WHERE box_type = 'ECC_CYCLE'          -- 或 'ECC_WO'
  AND wo = '{wo}'
  AND ecc_type IN ('ECC_SLC','ECC_TLC','ECC_QLC')
```

# 周ECC箱线（`dws_indicator_w`，`{flash_pn}_ecc_slc_wo` / `_ecc_tlc_wo` / `_ecc_qlc_wo`）

> 来源：DolphinScheduler `周报_WEEK_通用` → `to_slc_wo` / `to_tlc_wo` / `to_qlc_wo`（2026-08-11）。三个任务分别只取 `ECC_SLC` / `ECC_TLC` / `ECC_QLC`，逻辑一致。

## 业务定义
按 `wo × ecc_type × year_week × flash` 的 ECC 值箱线（每工单每周一个桶）。ECC 阈值判定用 `abnormal_slc/tlc/qlc`（异常阈值，来自 `dim_base_project`）。

## 算法步骤
1. **源**：`dws_fa_ecc_cycle_stat`，`grain = 'sn_cycle'`，`subitem_name = 'ECC_SLC'`（slc 任务；tlc/qlc 同理）
   - 时间窗：`dt BETWEEN date_trunc('week','${etl_dt}')-interval 1 day + 1 AND '${etl_dt}'`
   - 注：**此处 sn_cycle 直接读，不做 efuse_id 去重**（区别于现算箱线的 last_efuse_id_view）
2. **异常阈值**：`abnormal_slc/tlc/qlc` 来自 `dim_base_project`，为空时按 flash_pn 默认：
   - slc：N38B=100、SSV7=200、SSV8=200、N38B PSLC=100、WTS=200、Hynix 3DV7=0、3DV7(PGD)=0
   - tlc/qlc：N38B=160、SSV7=200、SSV8=200、N38B PSLC=160、WTS=200、Hynix 3DV7=0、3DV7(PGD)=0
3. **箱线算法**（同前）：累积计数 → q 位置(0.25/0.5/0.75) → `q_index` 用 `MIN(IF(slice_count_total >= pos, ecc_value, NULL))` → 须线 `LEAST/GREATEST` clamp → outliers
4. 输出到 `dws_indicator_w`：
   - `indicator_name = {flash_pn}_ecc_slc_wo`（slc；tlc/qlc 同理）
   - `dimension_json = {abnormal_slc, abnormal_tlc, abnormal_qlc, ecc_type}`
   - `indicator_value = {q1, median, q3, upper, lower, outliers, count_total}`

## 直接查表
```sql
SELECT year_week_number, wo, flash_pn, flash, indicator_value,
       get_json_object(dimension_json,'$.ecc_type') AS ecc_type,
       get_json_object(dimension_json,'$.abnormal_slc') AS abnormal_slc
FROM st_embed.dws_indicator_w
WHERE indicator_name = '{flash_pn}_ecc_slc_wo'     -- 或 _ecc_tlc_wo / _ecc_qlc_wo
  AND wo = '{wo}'
  AND year_week_number = '{周}'
```

## 注意/陷阱
- **三个任务三张 indicator_name**：`_ecc_slc_wo` / `_ecc_tlc_wo` / `_ecc_qlc_wo`，各对应一个测项类型。
- **与 ads_fa_fbc_cycle 的区别**：周ECC箱线在 `dws_indicator_w`（grain='sn_cycle'，直接读不去重）；落表箱线在 `ads_fa_fbc_cycle`（grain='wo_cycle'）。
- 异常阈值 `abnormal_*` 按 flash_pn 有默认值，别漏。

# 现算箱线（grain='sn_cycle'）：多工单 / 多cycle / 多批次

> 来源：数据查询模板（`@fun_name`：多工单箱线图数据 / 多cycle箱线图数据 / 多批次箱线图数据）。与落表箱线同算法，区别：
> **源是 `grain='sn_cycle'`（SN-cycle 级，含 result_guid），且先按"每 (wo, efuse_id) 最新记录"去重**（`last_efuse_id_view`，与 DPPM-BIBB 日表去重同一套新逻辑）。

## 三种粒度（仅 GROUP BY / PARTITION BY 键不同）
| 变体 | 分组键 | 输出标签 wo_format | 用途 |
|---|---|---|---|
| 多工单 | `wo, cycle_number, ecc_type` | `concat(wo,'_',cycle_number,'_',ecc_type)` | 单/多工单各 cycle 分布 |
| 多cycle | `cycle_number, ecc_type` | `concat(cycle_number,'_',ecc_type)` | 不看工单，只看 cycle 总体分布 |
| 多批次 | `wo, lot, cycle_number, ecc_type` | `concat(lot,'_',cycle_number,'_',ecc_type)` | 按批次（lot）看分布 |

## 去重前置（关键，2026-08-11 新逻辑）
先在 `dim_base_sn_di` 取每个 `(wo, efuse_id)` 最新记录的 guid：
```sql
SELECT DISTINCT guid FROM (
  SELECT guid, row_number() OVER(PARTITION BY wo, efuse_id ORDER BY time_end DESC) rn
  FROM st_embed.dim_base_sn_di
  WHERE etl_product_line = '{embed_type}'
    AND dt BETWEEN '{开始}' AND '{结束}'
) WHERE rn = 1
```
再用 `result_guid IN (上述 guid 集合)` 过滤 `dws_fa_ecc_cycle_stat`（grain='sn_cycle'）——即"每颗 SN 只算它最新的那次测试记录"。

## 静态 SQL（多工单变体，去掉动态参数；改分组键即得另外两种）
```sql
WITH last_efuse_id_view AS (
    SELECT DISTINCT guid FROM (
        SELECT guid, row_number() OVER(PARTITION BY wo, efuse_id ORDER BY time_end DESC) rn
        FROM st_embed.dim_base_sn_di
        WHERE etl_product_line = '{embed_type}'
          AND dt BETWEEN '{开始}' AND '{结束}'
    ) WHERE rn = 1
),
cumulative AS (
    SELECT wo, cycle_number, subitem_name AS ecc_type, ecc_value, ecc_cnt,
        SUM(ecc_cnt) OVER (PARTITION BY wo, cycle_number, subitem_name ORDER BY ecc_value) AS slice_count_total,
        SUM(ecc_cnt) OVER (PARTITION BY wo, cycle_number, subitem_name) AS count_total
    FROM st_embed.dws_fa_ecc_cycle_stat
    WHERE grain = 'sn_cycle' AND etl_product_line = '{embed_type}'
      AND result_guid IN (SELECT guid FROM last_efuse_id_view)
      AND dt BETWEEN '{开始}' AND '{结束}'
      AND wo = '{wo}'                    -- 多工单过滤；多cycle 去掉 wo；多批次再加 lot 过滤
),
max_min_ecc AS (
    SELECT wo, cycle_number, ecc_type, MAX(ecc_value) AS max_ecc, MIN(ecc_value) AS min_ecc
    FROM cumulative GROUP BY wo, cycle_number, ecc_type
),
q_position AS (
    SELECT wo, cycle_number, ecc_type, count_total,
        count_total*0.25 AS q1_position, count_total*0.5 AS q2_position, count_total*0.75 AS q3_position
    FROM cumulative GROUP BY wo, cycle_number, ecc_type, count_total
),
q_index AS (
    SELECT t.wo, t.cycle_number, t.ecc_type, t.count_total,
        MIN(IF(a.slice_count_total >= t.q1_position, a.ecc_value, 9999999)) AS q1_index,
        MIN(IF(a.slice_count_total >= t.q2_position, a.ecc_value, 9999999)) AS q2_index,
        MIN(IF(a.slice_count_total >= t.q3_position, a.ecc_value, 9999999)) AS q3_index
    FROM q_position t JOIN cumulative a
      ON a.wo=t.wo AND a.cycle_number=t.cycle_number AND a.ecc_type=t.ecc_type AND a.count_total=t.count_total
    GROUP BY t.wo, t.cycle_number, t.ecc_type, t.count_total
),
q_result AS (
    SELECT a.wo, a.cycle_number, a.ecc_type, b.count_total,
        b.q1_index AS q1, b.q2_index AS median, b.q3_index AS q3, b.q3_index-b.q1_index AS iqr,
        LEAST(b.q3_index+1.5*(b.q3_index-b.q1_index), a.max_ecc) AS upper_ecc,
        GREATEST(b.q1_index-1.5*(b.q3_index-b.q1_index), a.min_ecc) AS lower_ecc
    FROM max_min_ecc a JOIN q_index b
      ON a.wo=b.wo AND a.cycle_number=b.cycle_number AND a.ecc_type=b.ecc_type
)
SELECT CONCAT(a.wo,'_',a.cycle_number,'_',a.ecc_type) AS wo_format,
       a.cycle_number, q1, median, q3, iqr,
       upper_ecc AS upper_val, lower_ecc AS lower_val, a.count_total AS cnt,
       TO_JSON(FILTER(COLLECT_LIST(b.ecc_value), v -> v > a.upper_ecc OR v < a.lower_ecc)) AS cur_list
FROM q_result a JOIN cumulative b
  ON a.wo=b.wo AND a.cycle_number=b.cycle_number AND a.ecc_type=b.ecc_type
GROUP BY a.wo, a.cycle_number, a.ecc_type, q1, median, q3, iqr, upper_ecc, lower_ecc, a.count_total
ORDER BY a.wo, a.cycle_number, a.ecc_type
```

## 注意/陷阱
- **不是近似百分位**：用累积计数精确定位，不用 `approx_percentile`（区别于 FBB 周分布）。
- **outliers/cur_list 是 ECC 值集合**（JSON 数组），不是数量；数量用 `GET_JSON_ARRAY_SIZE`。
- **upper/lower 已 clamp** 到 [min_ecc, max_ecc]，须线不会超出真实数据范围。
- **q_index 未命中用哨兵 9999999**（`min(if(slice_count_total>=位置, ecc_value, 9999999))`）；桶太小时 q 位置可能落在同一 ecc_value 上，q1=median=q3 正常。
- 现算箱线必须先做 `last_efuse_id_view` 去重，否则一颗 SN 的多次测试会重复计入（与 BIBB 日表去重一致）。
- 落表箱线 grain='wo_cycle'，现算箱线 grain='sn_cycle'，查数先确认 grain 别混。
- 输出字段名：落表用 `q1/median/q3/upper/lower/outliers/count_total`；现算用 `q1/median/q3/iqr/upper_val/lower_val/cnt/cur_list`，别混。
