# 测试工单 / 测试样品口径（`{flash_pn}_week_test`）

> 来源：DolphinScheduler `周报_WEEK_通用` → `周测试 指标-DWS层`（2026-08-11）。
> 落表：`dws_indicator_w`，`indicator_name = {flash_pn}_week_test`，`indicator_value` = JSON `{test_wo_cnt, test_sn_cnt}`。

## 业务定义
每周测试**工单数**（`test_wo_cnt`）与**样品数**（`test_sn_cnt`，去重 guid 数）统计，按 `flash_pn × project × product_type` 维度。
反映本周实际投入测试的范围（多少工单、多少颗）。

## 算法步骤
1. **源**：`dwd_dut_result`（DUT 测试明细）
2. **过滤**：
   - `station in ('MT1','MT1R')`
   - **排除项目清单**：`project NOT IN ('FL31BE','FL223E','FL221E','YL200E','YL201E','YL500E','YL501E','YL220E','YL505E','YL506E','YL507E','YL100E','NA','','test','YL-AHGA','YL-AHGC','YL-AHGB','YL-GCGF')`
   - 周时间窗 `dt BETWEEN date_trunc('week','${etl_dt}') AND '${etl_dt}'`
3. **flash 拆分**：`new_flash = explode(split(flash, '\\+'))` —— flash 字段可能用 `+` 连接多颗粒，拆开后分别统计
4. **flash_pn 归一**：`new_flash = 'YMN0ATF1W00MBE' → 'YMTC_SQS(FL412E)'`；`'YMN0BQF1W00MBE' → 'YMTC_PTS(FL412E)'`；否则取 `flash_pn`
5. **样品数**：按 `(year_week, product_type, wo, project, flash, new_flash, flash_pn, data_source, item_control, pn, software_information)` 维度 `pass = count(distinct guid)`
6. **周汇总**：`test_wo_cnt = count(distinct wo)`，`test_sn_cnt = sum(pass)`，按 `year_week × product_type × project × flash_pn`
7. `indicator_name = {flash_pn}_week_test`，`indicator_value = {test_wo_cnt, test_sn_cnt}`

## 直接查表
```sql
SELECT year_week_number, flash_pn, project, product_type, indicator_value
FROM st_embed.dws_indicator_w
WHERE indicator_name = '{flash_pn}_week_test'
  AND year_week_number = '{周}'
  AND project = '{project}'
```
`indicator_value`：`$.test_wo_cnt`（测试工单数）、`$.test_sn_cnt`（测试样品数）。

## 现算（表里没有的周期）
按算法步骤换时间窗，从 `dwd_dut_result` 现算：
```sql
SELECT COUNT(DISTINCT wo) AS test_wo_cnt,
       COUNT(DISTINCT guid) AS test_sn_cnt
FROM st_embed.dwd_dut_result
WHERE station IN ('MT1','MT1R')
  AND project NOT IN ('FL31BE','FL223E','FL221E','YL200E','YL201E','YL500E','YL501E','YL220E','YL505E','YL506E','YL507E','YL100E','NA','','test','YL-AHGA','YL-AHGC','YL-AHGB','YL-GCGF')
  AND dt BETWEEN '{开始}' AND '{结束}'
  AND flash_pn = '{flash_pn}'
```

## 注意/陷阱
- **排除项目清单是硬过滤**，别漏；这些项目不参与周测试统计。
- **flash 可能用 `+` 连接多颗粒**，统计 flash_pn 前要 `explode(split(flash,'\\+'))`（周表已做归一，现算时别忘）。
- **test_sn_cnt 是去重 guid 数**（不是行数），test_wo_cnt 是去重工单数。
- YMTC 特定 flash 归一成 `YMTC_SQS(FL412E)`/`YMTC_PTS(FL412E)`。
