# 温度口径（`{flash_pn}_temp_week`）

> 来源：DolphinScheduler `周报_WEEK_通用` → `周温度分布`（2026-08-11）。
> 落表：`dws_indicator_w`，`indicator_name = {flash_pn}_temp_week`，`indicator_value` = JSON `{temp, sn_count}`，`dimension_json` = `{cycle_number, die_number}`。

## 业务定义
每周每个 `(cycle_number, die_number)` 下，温度值（`nand_temp_end`，已 > 阈值 `temp_cof`）的 SN 数量分布。
即：哪些 (cycle, die) 在什么温度档上有多少颗 SN，用于温度分布/异常监控。

## 算法步骤
1. **源**：`dwd_power_temperature_di`（温度明细）JOIN `dim_base_project`
   - 关联键：trim 后 `project / software_information / flash / item_control(like) / pn(like) / flash_pn`
   - `temp_cof`（温度系数阈值）来自 `dim_base_project`，为空取 0
2. **过滤**：
   - `nand_temp_end is not null and nand_temp_end <> '#N/A' and nand_temp_end <> ''`
   - 周时间窗 `dt BETWEEN date_trunc('week','${etl_dt}') AND '${etl_dt}'`
3. **温度值**：`temp = cast(nand_temp_end as int)`
4. **超阈值过滤**：`where temp > temp_cof` —— 只统计超过温度系数阈值的记录
5. **聚合**：按 `flash_pn, cycle_number, die_number, temp, year_week_number, project, product_type, data_source` 分组，`sn_count = count(dut_sn)`
6. `indicator_name = {flash_pn}_temp_week`，`indicator_value = {temp, sn_count}`
7. `year_week_number` 按 `date_add(trunc(dt,'week'),3)` 归周

## 直接查表
```sql
SELECT year_week_number, flash_pn, project, product_type, indicator_value,
       get_json_object(dimension_json,'$.cycle_number') AS cycle_number,
       get_json_object(dimension_json,'$.die_number') AS die_number
FROM st_embed.dws_indicator_w
WHERE indicator_name = '{flash_pn}_temp_week'
  AND year_week_number = '{周}'
  AND get_json_object(dimension_json,'$.cycle_number') = {cycle}   -- 可选
```
`indicator_value`：`$.temp`（温度档）、`$.sn_count`（该温度档 SN 数）。

## 现算（表里没有的周期）
按算法步骤换时间窗，从 `dwd_power_temperature_di` × `dim_base_project` 现算：
```sql
SELECT a.flash_pn, a.cycle_number, a.die_number,
       CAST(a.nand_temp_end AS INT) AS temp, COUNT(DISTINCT a.dut_sn) AS sn_count
FROM st_embed.dwd_power_temperature_di a
JOIN st_embed.dim_base_project b
  ON trim(a.project)=trim(b.project) AND trim(a.software_information)=trim(b.software_information)
 AND trim(a.flash)=trim(b.flash) AND trim(a.item_control) LIKE concat('%',trim(b.item_control),'%')
 AND trim(a.pn) LIKE concat('%',trim(b.pn),'%') AND trim(a.flash_pn)=trim(b.flash_pn)
WHERE a.nand_temp_end IS NOT NULL AND a.nand_temp_end <> '#N/A' AND a.nand_temp_end <> ''
  AND CAST(a.nand_temp_end AS INT) > COALESCE(b.temp_cof, 0)
  AND a.dt BETWEEN '{开始}' AND '{结束}'
GROUP BY a.flash_pn, a.cycle_number, a.die_number, CAST(a.nand_temp_end AS INT)
```

## 注意/陷阱
- **只统计超阈值温度**（`temp > temp_cof`），不是全部温度；`temp_cof` 来自 `dim_base_project`（默认 0）。
- 温度取 `nand_temp_end`（nand 结束温度），有 '#N/A' 等脏值要先过滤。
- 分布粒度是 `(cycle, die)`，同一 flash_pn 下可能多 die；温度分布/占比要按此粒度理解。
- 这是温度**分布**（每档 SN 数），不是温度极值/均值。
