# 电流口径（`{flash_pn}_{item_name}_current_week`）

> 来源：DolphinScheduler `周报_WEEK_通用` → `周电流分布-DWS`（2026-08-11）。
> 落表：`dws_indicator_w`，`indicator_name = {flash_pn}_{item_name}_current_week`，`indicator_value` = JSON `{q1, median, q3, upper, lower, outliers, mean, std, 3sigma, 6sigma, min, max}`，`dimension_json` = `{cur_threshold, item_name, subitem_name}`。

## 业务定义
每周每个 `(wo × flash_pn × item_name × subitem_name)` 的电流值分布统计：箱线（q1/median/q3/须线/离群）+ 均值/std/3σ/6σ。
即"电流箱线" + 电流分布监控。**四分位用 `approx_percentile`（非累积计数精确法，区别于 ECC 箱线）**。

## 算法步骤
1. **源**：`dwd_power_current_di`（电流明细）JOIN `dim_base_project`（`cur_threshold` 电流阈值，为空取 999999999）
   - 关联键：trim 后 `project / software_information / flash / item_control / pn`
2. **测项过滤（按产品线，很重要）**：
   - `etl_product_line = 'emmc'` → `subitem_name in ('SleepIccIccq')`
   - `etl_product_line = 'ufs'` 且 `project not like 'FL4%'` → `subitem_name in ('SleepIccIccq')` 或 `item_name in ('Sleep_VCC','Sleep_VCCQ','Standby_VCC','Standby_VCCQ','Active_Read_VCC','Active_Read_VCCQ') and subitem_name in ('VCC','VCCQ2')`
   - `etl_product_line = 'ufs'` 且 `project like 'FL4%'` → 一组 ICC/ICCQ 电流测项（`IDLE_ICC*`, `ACTIVE_*_ICC`, `SLEEP_ICC`, `WRITE_BOOSTER_ICC`, `POWER_DOWN_ICC` 等）或 VCC 测项（`IDLE_VCC`/`Active_*_VCC`/`Sleep_VCC`/`Write_Booster_VCC`/`Power_Down_VCC` 等）
   - 另过滤 `station in ('MT1','MT1R')`，周时间窗
3. **每 SN 只留最新**：`row_number() over(partition by wo, data_source, product_type, efuse_id, flash_pn order by time_end desc) rn`，取 `rn=1`
4. **箱线**（box_info）：按 `wo, flash_pn, cur_threshold, software_information, project, item_name, subitem_name, flash, item_control, pn, year_week` 分组：
   - `q1/median/q3 = approx_percentile(current_value, 0.25/0.5/0.75)`
   - `iqr = q3-q1`，`upper = q3+1.5*iqr`，`lower = q1-1.5*iqr`
   - `outliers = filter(collect_set(current_value), v -> v > upper or v < lower)`
5. **统计**（statistic_info）：同分组维度：
   - `mean/std = AVG/STDDEV_POP`，`min/max`
   - `3sigma = mean + 3*std`，`6sigma = mean + 6*std`
6. 输出到 `dws_indicator_w`，`indicator_name = {flash_pn}_{item_name}_current_week`

## 直接查表
```sql
SELECT year_week_number, wo, flash_pn, flash, indicator_value,
       get_json_object(dimension_json,'$.item_name') AS item_name,
       get_json_object(dimension_json,'$.subitem_name') AS subitem_name,
       get_json_object(dimension_json,'$.cur_threshold') AS cur_threshold
FROM st_embed.dws_indicator_w
WHERE indicator_name = '{flash_pn}_{item_name}_current_week'
  AND wo = '{wo}'
  AND year_week_number = '{周}'
```
`indicator_value`：`$.q1/$.median/$.q3/$.upper/$.lower/$.outliers`（箱线）、`$.mean/$.std/$.3sigma/$.6sigma/$.min/$.max`（统计）。

## 现算（表里没有的周期）
按算法步骤换时间窗，从 `dwd_power_current_di` × `dim_base_project` 现算（测项过滤按产品线，别漏）：
```sql
SELECT a.flash_pn, a.item_name, a.subitem_name,
       approx_percentile(a.current_value, 0.25) AS q1,
       approx_percentile(a.current_value, 0.5)  AS median,
       approx_percentile(a.current_value, 0.75) AS q3,
       AVG(a.current_value) AS mean, STDDEV_POP(a.current_value) AS std
FROM st_embed.dwd_power_current_di a
JOIN st_embed.dim_base_project b
  ON trim(a.project)=trim(b.project) AND trim(a.software_information)=trim(b.software_information)
 AND trim(a.flash)=trim(b.flash) AND trim(a.item_control)=trim(b.item_control)
WHERE a.station IN ('MT1','MT1R')
  AND a.dt BETWEEN '{开始}' AND '{结束}'
  AND a.flash_pn = '{flash_pn}'
  -- 测项过滤需按 etl_product_line 补全（见算法步骤 2）
GROUP BY a.flash_pn, a.item_name, a.subitem_name
```

## 注意/陷阱
- **四分位是 approx_percentile**（近似），区别于 ECC 箱线的累积计数精确法。
- **测项过滤按产品线不同**（emmc vs ufs vs ufs FL4%），现算时必须套对，否则结果差很多。
- 只统计 `rn=1`（每 SN 最新一次电流记录）。
- 电流有 `cur_threshold` 阈值（来自 dim_base_project），箱线/统计不按阈值裁剪，但 dimension_json 会带出供判异常。
