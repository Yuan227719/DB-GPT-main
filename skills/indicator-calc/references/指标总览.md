## 底层表（非"指标"表，但参与计算）

| 表 | 作用 |
|---|---|
| `dws_fa_ecc_plane` | plane 级 ECC 分类计数（fbb/uecc/psf/esf/gbb/hecc/total）→ FBB 比率与 ECC 坏块源 |
| `dws_fa_ecc_die` / `dws_fa_ecc_cycle` | die 级 / cycle 级 ECC 坏块聚合（FBB/GbB/HEcC...） |
| `dws_fa_bb_block` / `dwd_fa_bb_block` | block 级坏块统计 / 明细（FBB/UECC/PSF/ESF/GBB...） |
| `dwd_mes_lot` | MES 生产明细（投入 work_amount / 良品 bin_amount）→ 良率 |
| `dim_base_project` | 项目配置：fbb_ratio / dppm_threshold / max_bibb_num / slc·tlc·qlc_threshold / bibb 映射 |
| `dim_base_wo_di` | 工单信息（amount、wo_status）→ DPPM 分母、工单状态 |
| `dwd_fa_ecc_plane_di` | plane 级 ECC 明细（ecc_value_plane 字符串） |
| `dwd_power_current_di` / `dwd_power_temperature_di` | 电流 / 温度明细（第二批指标） |

| `ads_fa_fbc_cycle` | ECC cycle 箱线图分析（四分位数/异常值） |

## 关键口径约定（所有指标通用）
- **周标识**：`year_week_number`，格式 `concat(year(date_add(trunc(dt,'week'),3)),'年第',weekofyear(dt),'周')`。
- **周时间窗**：`dt BETWEEN date_trunc('week','${etl_dt}') AND '${etl_dt}'`（含本周）；部分统计前推 N 周用 `date_add(trunc(...), -N*7)`。
- **测项过滤**：ECC 相关指标基本都限定 `subitem_name in ('ECC_SLC','ECC_TLC','ECC_QLC')`。
- **口径来源变更**：若下方文档与实际表数据冲突，以 DolphinScheduler 建表 SQL 为准（运行 `scripts/refresh_calc_docs.py` 重新提炼）。
