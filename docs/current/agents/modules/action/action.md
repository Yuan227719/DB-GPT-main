# 动作介绍

> 动作模块负责将 Agent 的决策转化为具体的结果。
> 该模块位于最下游的位置，直接与环境交互。
> 它受到配置、记忆和规划模块的影响。

## 动作概述

在 DB-GPT 中，任何 Agent 都必须拥有动作。

根据论文 [A survey on large language model based autonomous agents](https://link.springer.com/article/10.1007/s11704-024-40231-1)，可以从四个角度来理解：

### 动作目标

Agent 希望通过动作实现什么？

1. **任务完成**：完成特定任务，例如在软件开发中编写一个函数，或在游戏中制作一把铁镐。

2. **通信**：与其他 Agent 进行通信。

3. **环境探索**：探索不熟悉的环境以扩展感知范围，并在探索与利用之间取得平衡。

### 动作生成

动作是如何生成的？
1. **通过记忆回忆生成动作**。在这种策略中，动作通过根据当前任务从 Agent 记忆中提取信息来生成。任务和提取的记忆被用作提示词来触发 Agent 的动作。

2. **通过计划执行生成动作**。在这种策略中，Agent 按照预先制定的计划执行动作。

### 动作空间

可用的动作有哪些？
动作空间指的是 Agent 可以执行的所有可能动作的集合。通常，我们可以将这些动作大致分为两类：
(1) 外部工具和 (2) LLM 的内部知识。

### 动作影响

动作的后果是什么？

动作影响指的是动作执行后的结果。实际上，动作影响可以涵盖很多方面。

以下是一些动作影响的示例：
1. **改变环境**：Agent 可以通过动作直接改变环境状态，例如移动位置、收集物品和建造建筑物。
2. **改变内部状态**：Agent 执行的动作也可以改变自身，包括更新记忆、形成新计划、获取新知识等。
3. **触发新动作**：在任务完成过程中，一个 Agent 的动作可以由另一个动作触发。
