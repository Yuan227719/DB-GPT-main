# 知识资源

有时，智能体需要访问外部知识库来丰富其知识。
这里我们介绍 `RetrieverResource`，它是一种用于从外部知识库检索知识的资源。

目前，有两种类型的 `RetrieverResource`：
- `RetrieverResource`：一种用于从外部知识库检索知识的资源。
- `KnowledgeSpaceRetrieverResource`：`RetrieverResource` 类的一个具体实现，用于从 DB-GPT 的知识空间中检索知识。
它仅在您在 DB-GPT 环境（在 DB-GPT 网页服务器中运行）中运行智能体时生效。
