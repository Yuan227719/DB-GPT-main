# 资源介绍

资源是 DB-GPT 智能体与外部世界交互的桥梁。它们包括
工具、数据库、知识库等。

## 资源包含哪些内容？

- **工具（Tools）**：此类工具类似于某些函数调用中使用的工具。
- **数据库（Databases）**：您可以查询和分析数据库中的数据。
- **知识库（Knowledge Bases）**：可以使用外部知识库来丰富智能体的知识。
- **API**：您可以调用第三方 API 来获取数据或执行操作。
- **文件（Files）**：您可以读写某些文件。
- **第三方插件（Third-party Plugins）**：您可以使用第三方插件来丰富智能体的功能。
- ...

## 资源包

资源包是智能体可以使用的资源集合。它通常包含一些
工具、数据库、知识库等。

您可以将可选工具包装到 `ToolPack` 中，或将所有资源包装到 `ResourcePack` 中。
