# 安装概览

DB-GPT 提供了三种推荐的安装路径。请选择与您运行和管理项目方式最匹配的一种。

## 选择安装路径

| 方式 | 适用对象 | 场景 | 可获得的内容 |
|:-------|:---------|:---------|:-------------|
| <span style={{whiteSpace: 'nowrap'}}>[快速安装](/docs/installation/quick-install)</span> | macOS / Linux 上最快的首次运行 | 通过自动化环境设置和依赖安装，从源码快速启动最新 DB-GPT | 快速安装并启动最新源码项目，可选择高级配置 |
| <span style={{whiteSpace: 'nowrap'}}>[CLI 安装](/docs/getting-started/cli-quickstart)</span> | 偏好从 PyPI 安装的用户 | 一键启动并尝试稳定的 DB-GPT 版本，无需关注项目结构或配置细节 | 一行命令安装、交互式设置向导、配置文件管理 |
| <span style={{whiteSpace: 'nowrap'}}>[源码安装](/docs/getting-started/deploy/source-code)</span> | 开发者和自定义部署 | 需要修改源码、调试内部逻辑或将 DB-GPT 集成到自定义部署流水线中 | 完整仓库检出、可编辑配置、最大灵活性 |

## 何时选择每种方式

### 快速安装

适用于 MacOS / Linux 用户 -- 如果您想以最少的步骤安装，通过自动化环境设置和依赖安装快速启动最新 DB-GPT，请选择此方式。

### CLI 安装（推荐）

如果您想直接从 PyPI 安装 DB-GPT 并使用 `dbgpt` 命令交互式地设置配置文件，请选择此方式。

### 源码安装

如果您希望完全访问仓库以进行开发、调试或自定义集成，请选择此方式。
