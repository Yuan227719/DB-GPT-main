# Chat Excel

Chat Excel 意味着可以通过自然语言对话来解读和分析 Excel 数据。


<p align="left">
  <img src={'/img/chat_excel/excel.png'} width="720px" />
</p>


## 步骤

使用 Chat Excel 的步骤相对简单，主要分为以下几个步骤：
- 1.选择 Chat Excel 对话应用
- 2.上传 Excel 文档
- 3.开始对话

### 选择 `Chat Excel`

<p align="center">
  <img src={'/img/app/chat_excel_v0.6.jpg'} width="800px" />
</p>

### 上传 Excel 文档

<p align="center">
  <img src={'/img/app/chat_excel_upload_succ_v0.6.jpg'} width="800px" />
</p>


:::info 提示

⚠️ Excel 文件格式会转换为 `.csv` 格式
:::


上传成功后，默认会汇总内容并推荐一些提问策略。

### 开始对话

然后即可基于上传的文件开始对话。
