# Chat Data

Chat Data 能力是通过自然语言与数据进行对话。目前主要用于与结构化和半结构化数据的对话，可辅助进行数据分析和洞察。

:::info 提示

在开始数据对话之前，我们首先需要添加数据源
:::

## 步骤

要开始数据对话，需要经过以下步骤：
- 1.添加数据源
- 2.选择 ChatData
- 3.选择相应的数据库
- 4.开始对话

### 添加数据源

首先，在左侧选择[数据源](../datasources.md)进行添加，添加一个数据库。目前 DB-GPT 支持多种数据库类型。只需选择相应的数据库类型进行添加即可。这里我们以 MySQL 作为演示。演示的测试数据请参见[测试样例](https://github.com/eosphoros-ai/DB-GPT/tree/main/docker/examples/sqls)。
