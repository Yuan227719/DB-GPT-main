# Chat DB

`Chat DB` 的目标是创建专业的数据库专家，定位为 LLM As DBA，通过与数据库对话来完成数据库性能分析、优化等工作。目前 ChatDB 仅具备一些基础能力，将随着社区的迭代逐步增强。


## 步骤

Chat DB 的使用流程主要包括以下步骤：
- 1.选择 Chat DB
- 2.添加数据源（与数据对话）
- 3.选择基础模型和数据库
- 4.开始对话
