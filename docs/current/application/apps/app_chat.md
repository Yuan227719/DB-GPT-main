# 应用对话

在线对话界面提供了主要的对话能力，展示了历史对话记录以及当前正在对话的应用。如下图所示，点击任意智能应用也会跳转到此界面。

<p align="center">
  <img src={'/img/app/app_chat_v0.6.jpg'} width="800px" />
</p>

在对话界面中，支持刷新、暂停对话等一系列操作。具体操作按钮位于右下角的编辑框中。同时，对话框还提供了多种参数选择，例如模型选择、温度参数调整、文件上传等。

<p align="center">
  <img src={'/img/app/app_chat_op_v0.6.jpg'} width="800" />
</p>

如果在使用过程中发现新的问题或有好的想法，也可以直接在 Github [issue](https://github.com/eosphoros-ai/DB-GPT/issues) 上反馈。
