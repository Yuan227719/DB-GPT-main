# 升级到 v0.5.1

## 概述

本指南适用于从 v0.5.0 升级到 v0.5.1。如果您使用 SQLite，
则无需升级数据库。如果您使用 MySQL，则需要升级数据库。

## 准备工作

### 备份数据库

为防止数据丢失，建议在升级前备份数据库。
备份方式根据您的数据库类型而定。

## 升级

### 停止 DB-GPT 服务

根据您的启动方式停止 DB-GPT 服务。

### 升级数据库

执行以下 SQL 来升级数据库。

**添加列**
```sql
USE dbgpt;
ALTER TABLE dbgpt_serve_flow
    ADD COLUMN `error_message` varchar(512) null comment '错误消息' after `state`;
```
