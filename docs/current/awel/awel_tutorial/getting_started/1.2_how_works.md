# 1.2 AWEL 的工作原理

## 引言

让我们再次查看上一节中的 DAG：

```python
import asyncio

from dbgpt.core.awel import DAG, MapOperator, InputOperator, SimpleCallDataInputSource

with DAG("awel_hello_world") as dag:
    input_task = InputOperator(
        input_source=SimpleCallDataInputSource()
    )
    task = MapOperator(map_function=lambda x: print(f"Hello, {x}!"))
    input_task >> task

dag.visualize_dag()
asyncio.run(task.call(call_data="world"))
```

这段代码包含几个新概念：`DAG`、`Operator` 和 `Task`。

- `DAG`：`DAG` 是一个表示**有向无环图（Directed Acyclic Graph）** 的类。它用于定义 task 的结构及其依赖关系。
- `Operator`：`InputOperator` 和 `MapOperator` 是算子的示例。算子是 DAG 中的一个节点。它可以是数据的来源、数据转换或数据输出。在此示例中，`InputOperator` 是数据来源，而 `MapOperator` 是数据转换。
- `Task`：Task 是算子的一个实例，它是一个动态概念。
- `Runner`：Runner 用于执行 DAG 中的 task。当我们调用 `task.call(call_data="world")` 时，我们正在使用一个 runner 来执行 task。`DefaultWorkflowRunner` 在同一进程中运行你的 task。而 `RayWorkflowRunner` 在 Ray 集群中运行你的 task（社区版本尚未实现）。

## DAG

### 什么是 DAG？

有向无环图（DAG）是一种图，它有一组顶点和一组有向边。边从一个顶点指向另一个顶点，并且图中没有环。在 AWEL 的上下文中，顶点是算子，边是算子之间的依赖关系。

## Operator

### 什么是 Operator？

算子是 DAG 中的一个节点。它可以是数据的来源、数据转换，或对 LLM 服务的调用。在 AWEL 的上下文中，算子是继承自 `dbgpt.core.awel.BaseOperator` 类的类。

根据输出数据的类型，算子有两种类型：**流式算子**和**非流式算子**。

### 基本算子

以下是一些用于构建更复杂算子的基本算子。

- `InputOperator`：此**非流式**算子用于从输入源获取数据。
- `MapOperator`：此**非流式**算子用于对输入数据应用函数并返回转换后的数据。
- `BranchOperator`：此**非流式**算子用于根据输入数据决定执行哪条路径。
- `JoinOperator`：此**非流式**算子用于将来自多个路径的数据合并到单个路径。
- `StreamifyAbsOperator`：此**流式**算子用于将非流式算子转换为流式算子。
- `UnstreamifyAbsOperator`：此**非流式**算子用于将流式数据转换为非流式数据。
- `TransformStreamAbsOperator`：此**流式**算子用于将流式数据转换为另一种流式数据。
- `ReduceStreamOperator`：此**非流式**算子用于将流式数据缩减为非流式数据。
- `TriggerOperator`：此**非流式**算子用于触发 task。它是一个特殊的 `InputOperator`。

### 高阶算子

- `RequestBuilderOperator`：此**非流式**算子用于根据输入数据构建模型请求。
- `LLMOperator`：此**非流式**算子用于调用 LLM 服务。
- `StreamingLLMOperator`：此**流式**算子用于调用 LLM 服务并期望流式响应。
- `LLMBranchOperator`：此**非流式**算子用于根据输入数据决定执行哪条路径。
- `OpenAIStreamingOutputOperator`：此**流式**算子用于将模型输出转换为与 OpenAI 兼容的流式数据。
- `ChatHistoryPromptComposerOperator`：此**非流式**算子用于构建一个高阶 task，以组合聊天历史提示。

## Task

### 什么是 Task？

Task 是算子的一个实例。它是无状态设计的，这意味着可以使用不同的输入数据多次执行该 task。

每个 task 可以从父 task 接收多个输入数据，并向子 task 返回单个输出数据。

## Runner

### 什么是 Runner？

Runner 是一个用于执行 DAG 中 task 的类。当我们通过 `task.call(call_data="world")` 调用 task 时，我们正在使用 runner 来执行 task。它将触发该 task 的所有父 task，然后执行该 task。

`DefaultWorkflowRunner` 在同一进程中运行你的 task。而 `RayWorkflowRunner` 在 Ray 集群中运行你的 task（社区版本尚未实现）。此外，你可以实现自己的 runner，以便在你自己的环境中运行你的 task。
