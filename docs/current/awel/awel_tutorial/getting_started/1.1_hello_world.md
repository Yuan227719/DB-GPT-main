# 1.1 Hello World

## 准备工作

在本教程中，我们将使用 `poetry` 来管理项目依赖。如果你还没有安装 `poetry`，可以按照[此处的说明](https://python-poetry.org/docs/)进行安装。

## 创建项目

首先创建一个新的 Python 项目。你可以随意命名；在本教程中，我们将其命名为 `awel-tutorial`。

建议在你的 home 目录下创建项目目录，但你可以将其放在任何你喜欢的位置。

打开终端并运行以下命令来创建项目目录和 AWEL 教程目录：

对于 Linux、macOS 或 PowerShell，请输入：
```bash
mkdir -p ~/projects
cd ~/projects
```

然后运行以下命令来创建新项目并切换到新目录：

```bash
poetry new awel-tutorial
cd awel-tutorial
```

项目的目录结构应如下所示：

```plaintext
awel-tutorial
├── README.md
├── awel_tutorial
│   └── __init__.py
├── pyproject.toml
└── tests
    └── __init__.py
```

## 添加 DB-GPT 依赖

```bash
poetry add "dbgpt>=0.5.1"
```

## 第一个 Hello World

接下来，你将创建一个简单的 DAG，用于在控制台打印 "Hello, world"。

现在，在 `awel_tutorial` 目录下创建一个名为 `first_hello_world.py` 的新文件，并添加以下代码：

```python
from dbgpt.core.awel import DAG, MapOperator

with DAG("awel_hello_world") as dag:
    task = MapOperator(map_function=lambda x: print(f"Hello, {x}!"))
task._blocking_call(call_data="world")
```

现在，项目的目录结构应如下所示：

```plaintext
awel-tutorial
├── README.md
├── awel_tutorial
│   ├── __init__.py
│   └── first_hello_world.py
├── poetry.lock
├── pyproject.toml
└── tests
    └── __init__.py

```

然后运行以下命令来执行代码：

```bash
poetry run python awel_tutorial/first_hello_world.py
```

你将在控制台中看到 "Hello, world!" 被打印出来。
```bash
Hello, world!
```

## AWEL 代码解析

让我们分解一下你刚刚编写的代码。

```python
with DAG("awel_hello_world") as dag:
    task = MapOperator(map_function=lambda x: print(f"Hello, {x}!"))
```

这段代码创建了一个名为 `awel_hello_world` 的新 DAG（有向无环图）。
`MapOperator` 是一个简单的算子，它接收一个函数并使用传递给它的数据调用该函数。
在此例中，该函数是一个 lambda 表达式，用于在控制台打印 "Hello, world!"。

`task` 是 `MapOperator` 类的实例。我们调用该 task 的 `call` 方法，
并将 `call_data` 参数设置为 `"world"`。

```python
task._blocking_call(call_data="world")
```
当你调用该 task 时，lambda 函数会使用你传递给它的数据（`"world"`）被执行。

`_blocking_call` 方法用于以阻塞方式调用 task。仅在此处用于测试，
我们将在下一节中找到更好的调用方式。

## 使用 `asyncio` 的 Hello World

AWEL 中所有 task 的调用都是异步的。此示例演示了如何使用 asyncio 运行 task。

在 `awel_tutorial` 目录下创建一个名为 `first_hello_world_asyncio.py` 的新文件，并添加以下代码：

```python
import asyncio

from dbgpt.core.awel import DAG, MapOperator

with DAG("awel_hello_world") as dag:
    task = MapOperator(map_function=lambda x: print(f"Hello, {x}!"))

asyncio.run(task.call(call_data="world"))
```

然后运行以下命令来执行代码：

```bash
poetry run python awel_tutorial/first_hello_world_asyncio.py
```

你将在控制台中看到 "Hello, world!" 被打印出来。
```bash
Hello, world!
```

## 包含两个 Task 的 Hello World

当调用单个节点时，我们可以向其传递数据。此示例演示了如何使用 `InputOperator` 将数据传递给 task。

在 `awel_tutorial` 目录下创建一个名为 `first_hello_world_two_tasks.py` 的新文件，并添加以下代码：

```python
import asyncio

from dbgpt.core.awel import DAG, MapOperator, InputOperator, SimpleCallDataInputSource

with DAG("awel_hello_world") as dag:
    input_task = InputOperator(
        input_source=SimpleCallDataInputSource()
    )
    task = MapOperator(map_function=lambda x: print(f"Hello, {x}!"))
    input_task >> task
    

asyncio.run(task.call(call_data="world"))
```

然后运行以下命令来执行代码：

```bash
poetry run python awel_tutorial/first_hello_world_two_tasks.py
```

你将在控制台中看到 "Hello, world!" 被打印出来。
```bash
Hello, world!
```

在这个例子中，我们有两个 task。第一个 task 是一个 `InputOperator`，它从 `SimpleCallDataInputSource` 获取数据。第二个 task 是一个 `MapOperator`，它从第一个 task 获取数据并在控制台打印 "Hello, world!"。

我们使用 `>>` 运算符来连接两个 task。该运算符用于定义 task 之间的父子关系，也称为 task 依赖关系。
你也可以使用 `set_downstream` 方法来定义 task 依赖关系，示例如下：

```python
input_task.set_downstream(task)
```

上述的单 task DAG 是双 task DAG 的一种特殊情况，其中没有使用 `InputOperator`。

```python
with DAG("awel_hello_world") as dag:
    task = MapOperator(map_function=lambda x: print(f"Hello, {x}!"))

asyncio.run(task.call(call_data="world"))
```

## DAG 可视化

安装 graphviz 包以可视化 DAG 图。

```bash
poetry add graphviz
```

修改 `first_hello_world_two_tasks.py` 文件，添加以下代码：

```python
dag.visualize_dag()
```

完整代码如下：

```python
import asyncio

from dbgpt.core.awel import DAG, MapOperator, InputOperator, SimpleCallDataInputSource

with DAG("awel_hello_world") as dag:
    input_task = InputOperator(
        input_source=SimpleCallDataInputSource()
    )
    task = MapOperator(map_function=lambda x: print(f"Hello, {x}!"))
    input_task >> task

dag.visualize_dag()
asyncio.run(task.call(call_data="world"))
```

再次运行 `first_hello_world_two_tasks.py`：

```bash
poetry run python awel_tutorial/first_hello_world_two_tasks.py
```

你将看到以下输出：

```bash
InputOperator(node_id=a307d921-3bd0-423d-80f0-30aa25aaa9fe)
 -> MapOperator(node_id=bdb335f8-179d-4e08-b1ec-3b58a52d1e84)
Hello, world!
```
