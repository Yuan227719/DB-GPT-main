# 4.1 AWEL 生命周期

## Task 生命周期钩子

Task 生命周期钩子是一组可以在 task 中实现的方法，用于在 task 生命周期的不同阶段执行操作。以下钩子可用：

- `before_dag_run`：在 DAG 运行之前执行
- `after_dag_end`：在 DAG 结束之后执行

### 示例

在 `awel_tutorial` 目录下创建一个新文件 `lifecycle_hooks.py`，并添加以下代码：

```python
import asyncio
from dbgpt.core.awel import DAG, MapOperator

class MyLifecycleTask(MapOperator[str, str]):
    async def before_dag_run(self):
        print("在 DAG 运行之前")

    async def after_dag_end(self):
        print("在 DAG 结束之后")

    async def map(self, x: str) -> str:
        return f"Hello, {x}!"

with DAG("awel_lifecycle_hooks") as dag:
    task = MyLifecycleTask()

print(asyncio.run(task.call("world")))
```

然后运行以下命令来执行代码：

```bash
poetry run python awel_tutorial/lifecycle_hooks.py
```

主要输出应如下所示：

```plaintext
在 DAG 运行之前
在 DAG 结束之后
Hello, world!
```
