# 3.1 HTTP 触发器

## 引言

在本章中，我们将开始专注于如何使用 AWEL 开发网络程序。首先，我们将创建一个简单的 HTTP 触发器，用于接收请求并返回响应。

`HttpTrigger` 是一个特殊的 `InputOperator`。

## 安装

我们已经在[前一章](/docs/awel/awel_tutorial/getting_started/1.1_hello_world#creating-a-project)中创建了一个名为 `awel-tutorial` 的项目，并添加了 `dbgpt` 依赖。

要使用 `HttpTrigger` 算子，我们需要安装 `fastapi` 和 `uvicorn` 包。

```bash
poetry add fastapi uvicorn
```

## 第一个 HTTP 触发器

在 `awel_tutorial` 目录下创建一个名为 `frist_http_trigger_hello.py` 的新文件，并添加以下代码：

```python
from dbgpt.core.awel import DAG, HttpTrigger, MapOperator, setup_dev_environment

with DAG("awel_hello_world") as dag:
    trigger_task = HttpTrigger(endpoint="/awel_tutorial/hello_world")
    task = MapOperator(map_function=lambda x: f"Hello, world!")
    trigger_task >> task  
    
setup_dev_environment([dag], port=5555)
```

然后运行以下命令来执行代码：

```bash
poetry run python awel_tutorial/frist_http_trigger_hello.py
```

主要输出应如下所示：

```plaintext

2024-03-03 16:26:57 | INFO | dbgpt.core.awel.trigger.trigger_manager | Include router <fastapi.routing.APIRouter object at 0x10ed64e50> to prefix path /api/v1/awel/trigger
INFO:     Started server process [69774]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:5555 (Press CTRL+C to quit)
```

在 AWEL 中，所有 HTTP 端点默认以 `/api/v1/awel/trigger` 为前缀。

现在，打开一个新的终端并运行以下命令向服务器发送请求：

```bash
curl -X GET http://127.0.0.1:5555/api/v1/awel/trigger/awel_tutorial/hello_world
```

输出应如下所示：

```plaintext
"Hello, world!"
```

恭喜！你已经创建了第一个 HTTP 触发器。

然后，你可以通过在终端中按 `Ctrl+C` 来停止服务器。

## 工作原理

在上面的代码中，我们创建了一个 `HttpTrigger` 算子和一个 `MapOperator` 算子。
`HttpTrigger` 定义了 HTTP 请求的端点，请求方法默认为 "GET"。

`setup_dev_environment` 函数用于启动服务器并注册 DAG，如果 DAG 中存在 `HttpTrigger` 算子，它将阻塞主线程并默认监听 5555 端口。

当服务器收到请求时，它将调用 `MapOperator` 算子来处理请求并返回结果。

在 `HttpTrigger` 中，你可以配置端点、方法、请求体、响应体、响应状态码等。
